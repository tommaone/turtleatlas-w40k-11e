Strong
Strength notes
11e Goonhammer Faction Pack Review (2026-06-09) calls Argent Assault 'a solid Detachment' and the Dauntless Champions rule 'straight up good', noting +1 to Wound is exactly what S6 Grey Knights melee needs to punch into hard targets; 'for 1DP, if you're leaning in to Paladins, this is a no brainer': https://www.tabletopbattles.com/40k-11th-edition-faction-pack-review-grey-knights/. Mechanical basis: the +1 to Wound is a consistent, always-on buff whenever Paladins fight a tougher target, rewarding the unit type the detachment is built around.
Limitations
Rule only affects Paladin Squad units, +1 to Wound applies only when the attack Strength is below the target's Toughness, Provides no benefit to ranged or non-fighting roles
